## 説明情報1

**説明見出し1**：このテーマについて

**説明詳細1**（エディタの「ソース」に貼る）

```html
<p>BcLpRecruitTheme は、中小企業の採用のための、1ページのランディングページ（LP）テーマです。</p>
<p>トップの固定ページ1枚に、セクションを BurgerEditor のブロックで並べる構成です。セクションの追加・削除・並べ替えは、ブロック操作だけでできます。セクションの番号（01, 02 …）は自動で振られます。</p>
<ul>
<li>ヒーロー／数字で見る会社／私たちについて／仕事内容／社員の声／1日の流れ／働く環境・制度／募集要項／選考の流れ／よくある質問／応募（CTA）</li>
<li>大見出しブロックの「ID設定」に英字（例 jobs）を入れると、ヘッダーのナビに自動で載ります</li>
<li>応募フォームは入力 → 確認 → 完了の3画面。履歴書・職務経歴書のファイル添付（PDF・Word・Excel）つき。項目はメールフィールドで追加・並べ替えできます</li>
<li>「まずは話を聞いてみる」ボタンから開くと、応募の種類で「カジュアル面談を希望する」が選ばれた状態になります</li>
<li>テーマ設定の4色（メイン／サブ／リンク／ホバー）で全体の配色が変わります。どの色にしても文字が読みやすいよう、文字の濃さと白黒を自動で調整します。ロゴもテーマ設定で変更できます</li>
<li>初期データ：見本サイト一式（default）と最小構成（empty）</li>
<li>レスポンシブ（PC／スマホ）、prefers-reduced-motion 対応</li>
</ul>
```

**説明画像1**：`pc-1-hero.png`（PC：ヒーロー・数字で見る会社）

<li>同じ画面で初期データ「default」（見本サイト）または「empty」（最小構成）を読み込みます</li>
</ol>
<p><strong>初期データを読み込むと、ユーザー以外のデータ（固定ページ・メールフォーム・サイト基本設定など）は初期化されます。運用中のサイトでは読み込まないでください。</strong></p>

## 説明情報4

**説明見出し4**：応募フォームと制限事項

**説明詳細4**

```html
<h4>履歴書・職務経歴書の添付</h4>
<ul>
<li>添付できる形式は PDF・Word・Excel、サイズは 5MB までです（メールフィールドのオプションで変更できます）</li>
<li>添付されたファイルは管理者宛てのメールに添付され、サーバーの外から直接は開けない場所に保存されます</li>
<li>サーバーの PHP の設定（upload_max_filesize・post_max_size）が小さい場合は、サーバー側の設定も確認してください</li>
</ul>
<h4>制限事項</h4>
<ul>
<li>baserCMS5.4.1以前では、ファイル項目に「ファイルサイズチェック」があるとフォームが送信できません（baserCMS 本体の不具合。5.4.2で修正）。5.4.1以前で使う場合は、メールフィールド「履歴書・職務経歴書」の拡張バリデーションから「ファイルサイズチェック」を外してください</li>
<li>会社名・職種などは各ブロックに直接書くため、変更時は複数の場所を直す必要があります</li>
<li>「働く環境・制度」のアイコンは項目ごとに選べません。並び順で決まります</li>
</ul>
```
